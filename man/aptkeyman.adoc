== Name

aptkeyman - manage third-party APT OpenPGP keys

== Synopsis

*aptkeyman* _COMMAND_ [_OPTION_]...

== Description

*aptkeyman* keeps a local SQLite database of APT repository signing keys
(name, URL pattern, fingerprint, key URL, key blob, accept/deny state).
It scans `/etc/apt/sources.list` and `sources.list.d`, downloads missing
keyring files, and can seed facts from `/usr/share/keyrings`,
`/etc/apt/keyrings`, and `apt-get update` missing-key errors.

Typical flow:

----
aptkeyman seed --apt-log /tmp/apt-update.out
sudo aptkeyman download
sudo apt-get update
----

== Commands

*download*::
  Download and install missing keyring files for accepted facts matched by
  configured apt sources. Fetches run concurrently (`-j`/`--jobs`).
  Proxy: `http_proxy`/`https_proxy`/`no_proxy` or
  `--proxy`/`--http-proxy`/`--https-proxy`/`--no-proxy`.
  Per-key `proxy_mode` in the DB selects auto / always / never / explicit URL.

*update*::
  Refresh all keys used by sources lists (concurrent fetches; same proxy
  options as *download*), then purge managed key files that are no longer
  referenced. Keys without a `keyurl` keep their stored blob.

*verify*::
  Verify on-disk keyring files against fingerprints stored in the database.

*seed*::
  Seed the database from packaged well-known keys, local keyring directories,
  and optional `apt-get update` diagnostics (`--apt-update` or `--apt-log`).

*scan*::
  Show apt sources and which database facts match them.

*list*, *show*, *accept*, *deny*, *add*, *fetch*::
  Inspect and edit key facts.

*export*, *import*::
  Dump or merge JSON key databases.

*gui*::
  Open a wxPython management window (requires `python3-wxgtk4.0`).

*version*, *help*::
  Version information and usage.

== Files

`~/.local/share/aptkeyman/aptkeyman.db`::
  Per-user key fact database.

`/usr/share/aptkeyman/wellknown.json`::
  Packaged well-known publisher entries.

`/usr/share/aptkeyman/aptkeyman.db`::
  Prebuilt database with downloaded key blobs (when built with network).

`/etc/apt/keyrings/`::
  Default destination for installed keyring files.
